# Tarefas dos 60 minutos

Marque as caixinhas conforme for fazendo. A ordem importa.

## Começo (10 minutos)

- [ ] Ler o README.md.
- [ ] Conferir o CLAUDE.md com o grupo. Preencher a parte "O que nunca mexer" com o que só a empresa sabe.
- [ ] Abrir o index.html no navegador e ver se a tela aparece com a planilha de exemplo.
- [ ] Se a planilha não carregar, rodar `npx serve .` e abrir o endereço que aparecer.

## Primeiro passo da proposta principal (20 minutos)

- [ ] Escrever no papel a lista dos sites que o RH consulta hoje, na ordem que faz.
- [ ] Comparar com a lista que já está na tela. Anotar o que sobra e o que falta.
- [ ] Pedir ao Claude Code para trocar a lista de consultas pela lista real (use o pedido 1 do README).
- [ ] Testar: digitar um nome inventado e um CPF inventado, abrir um link, colar um texto e ver o resumo aparecer.

## Ficha (15 minutos)

- [ ] Clicar em "Gerar ficha em PDF" e conferir se a ficha tem tudo que o gestor precisa ver.
- [ ] Se faltar algo na ficha, pedir ao Claude Code para incluir (use o pedido 2 do README).
- [ ] Conferir que o aviso "esta ficha não decide a contratação" está no PDF.

## Se sobrar tempo (10 minutos)

- [ ] Pedir um resumo melhor do texto colado (use o pedido 3 do README).
- [ ] Anotar as dúvidas para levar ao jurídico: o que pode ou não pesar na decisão.

## Fechamento (5 minutos)

- [ ] Salvar uma versão: copiar a pasta inteira com o nome `pesquisa-candidato-rh-v1` ou pedir ao Claude Code para salvar uma versão.
- [ ] Anotar no DIARIO.md: o que fizemos, o que decidimos, o que falta, onde paramos.
